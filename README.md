## `// 01` — What Is ContractLens?

> **ContractLens** turns the black box of legal contracts into something you can actually understand — in seconds.

Most people sign contracts without fully reading them. Not because they're careless — because legal language is dense, obfuscated, and deliberately opaque. ContractLens fixes that.

Upload any PDF contract. ContractLens extracts the text, fires it through **Gemini AI**, and surfaces the risky clauses — explained in plain English, scored by severity, and delivered in a clean Android interface.

It's not a PDF reader. It's a risk engine.

## `// 05` — Installation

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/ContractLens.git

# 2. Open in Android Studio (Hedgehog or later recommended)
cd ContractLens && studio .

# 3. Add your Gemini API key
# Create or edit: local.properties
echo "GEMINI_API_KEY=your_key_here" >> local.properties

# 4. Sync Gradle dependencies
# Android Studio → File → Sync Project with Gradle Files

# 5. Run on Contractice or emulator (API 26+)
# Run → Run 'app'
```

> **Prerequisites:** Android Studio Hedgehog+, JDK 17, Android SDK 34, Gemini API key from [Google AI Studio](https://aistudio.google.com)

## `// 06` — Engineering Challenges

Real problems solved during Contractelopment — not theory, not tutorials.

<br/>

**`[ 01 ]` Gradle API Key Injection**
Securely injecting the Gemini API key from `local.properties` into the build via `buildConfigField` — keeping secrets out of source control without sacrificing runtime access.

**`[ 02 ]` Gemini API Integration**
Designing the prompt schema to extract structured risk data from unstructured legal text — not just summarizing, but forcing the model into clause-level specificity with consistent output format.

**`[ 03 ]` Android Async Operations**
Managing long-running PDF parsing and API calls without blocking the main thread. Coroutine scopes tied to ViewModel lifecycle to prevent memory leaks and zombie operations.

**`[ 04 ]` PDF Text Extraction at Scale**
PDFBox on Android has constraints the desktop version doesn't. Handled encoding edge cases, multi-column layouts, and contracts with embedded tables that naive extractors mangle.

**`[ 05 ]` API Quota & Error Handling**
Gemini free-tier quota limits hit fast during Contractelopment. Implemented exponential backoff, graceful error states, and user-facing feedback that doesn't just say "something went wrong."

**`[ 06 ]` Prompt Engineering for Legal Context**
Getting Gemini to produce consistent, structured output on wildly different contract types — NDAs, employment agreements, SaaS terms — required iterative prompt refinement with explicit output schema definitions.
